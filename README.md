# University Robot Guide (Python + Vosk + pyttsx3)

Минимальная архитектура и рабочий прототип голосового робота-гида для университета.

## 1) Архитектура

Система работает циклически:

1. **UI ожидания** — окно выбора языка (RU/EN/KK).
2. **Инициализация** — загрузка STT-модели Vosk, базы интентов, TTS-движка pyttsx3.
3. **Основной цикл**:
   - потоковый прием аудио с микрофона;
   - распознавание речи (Vosk);
   - проверка горячего слова (`Робот` / `Robot`);
   - определение интента по ключевым словам;
   - генерация ответа;
   - озвучивание ответа.
4. **Завершение/возврат**:
   - если распознан интент завершения — прощание и возврат на экран выбора языка;
   - при ошибках распознавания действует правило: **повтор → повтор → завершение с логом**.

Линейный поток данных:

`UI -> Init -> STT -> Intent -> Response -> TTS -> UI`

## 2) Структура проекта

- `main.py` — GUI + основной цикл + модули.
- `intents.json` — база интентов, ответов и wake words для 3 языков.
- `requirements.txt` — зависимости.
- `robot_guide.log` — лог ошибок во время выполнения.

## 3) Установка

```bash
pip install -r requirements.txt
```

Скачайте модели Vosk и разместите в `models/`:

- `models/vosk-model-small-ru-0.22`
- `models/vosk-model-small-en-us-0.15`
- `models/vosk-model-small-kz-0.15`

Источник моделей: https://alphacephei.com/vosk/models

## 4) Запуск

```bash
python main.py
```

## 5) Минимальная база интентов (робот-гид университета)

Поддерживаются:

- приветствие;
- библиотека;
- столовая;
- приемная комиссия;
- деканат;
- расписание;
- помощь;
- завершение диалога.

## 6) Примечания по Raspberry Pi / Windows

- Код кроссплатформенный, но для Raspberry Pi рекомендуется Linux-окружение и локальная настройка аудиоустройств.
- В Windows можно тестировать логику и GUI, но качество STT/TTS зависит от драйверов микрофона и системного аудио.
